List the Vercel projects the connected account can reach.

Use this to find the exact project name before calling the deployment tools, and to see which framework and Node.js version a project builds with. Only projects that belong to the account or team the token is authorized for are returned.

Requires a Vercel access token. The tool fails closed when no token is configured, when the token was rejected, or when Vercel returns a project outside the authorized account.
