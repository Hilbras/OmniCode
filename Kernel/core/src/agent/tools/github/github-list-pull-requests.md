List the pull requests of one GitHub repository.

Use "owner/name" for the repository and "open", "closed", or "all" for the state (default "open"). Each summary reports the author, the head and base branches, and whether the pull request is a draft, which is enough to decide whether the pull request needs a closer look with the get-pull-request tool.

Requires a connected GitHub account whose authorization covers the repository. The tool fails closed when the repository is outside the granted repository set.
