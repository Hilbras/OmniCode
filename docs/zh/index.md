# Omnicode CLI

下一代智能体的起点。

Omnicode CLI 是一个在终端中运行的 AI 编程智能体。它能读写代码、执行命令、搜索文件、
抓取网页，并根据反馈决定下一步。它开箱即用地支持 Omnicode 模型，也可以配置
Anthropic、OpenAI、Google 等兼容提供商。
