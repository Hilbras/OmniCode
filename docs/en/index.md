# Omnicode CLI

The Starting Point for Next-Gen Agents.

Omnicode CLI is an AI coding agent that runs in your terminal. It reads and edits
code, runs shell commands, searches files, fetches pages, and chooses the next
step from the feedback it receives. It works out of the box with Omnicode models
and can be configured for Anthropic, OpenAI, Google, and other compatible
providers.
